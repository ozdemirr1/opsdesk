# Implement member addition and membership reactivation

Local planning ID: F08. This is not a GitHub issue number.

Suggested priority: P1. Type: feature.
Published issue: [#17](https://github.com/ozdemirr1/opsdesk/issues/17).

Snapshot of the initial published scope, 13 September 2026. Follow GitHub for
current status and scope discussion; this file is not a live progress tracker.

## Goal

Add existing active Users or reactivate their retained memberships within explicit role boundaries.

## Scope

- POST /organizations/{organization_id}/memberships with email/role.
- POST /organizations/{organization_id}/memberships/{membership_id}/reactivation with role.

## Out of scope

- User creation, invitations/email/consent, global search, promotion, ordinary role edits/deactivation/ownership transfer.

## Acceptance criteria

- Require active User, active admin/owner membership, active Organization. Customer/agent denied.
- Only customer/agent may be granted by either endpoint; admin promotion is separate.
- Canonical exact-email addition requires active existing User: missing/inactive target uses 400 user_not_addable; existing membership in any state uses 409 membership_exists, according to finalized precedence.
- Addition creates active membership and returns 201; reactivation updates an inactive same-tenant non-owner target with active global User and returns 200.
- Reactivation preserves membership/User/Organization identity and explicitly assigns the requested role; never restores old privileges automatically.
- No global account activation or owner/self-management bypass. Safe MembershipResponse after commit; rejection/failure changes no business state.

## Expected tests or review evidence

- Admin/owner success, customer/agent denial, target missing/inactive, duplicate active/inactive memberships.
- Concurrent duplicate addition yields one membership; reactivation preserves ID and rejects owner/active/foreign/inactive-User target per finalized error contract.
- Invalid elevated role, rollback and safe response projections.
